# Перцептивное аудиохеширование для обнаружения звуковых событий в IoT

[English](README.md) | **Русский**

Референсная реализация для бакалаврской работы о компактном перцептивном
аудиохешировании. Вместо передачи исходного аудио периферийное устройство
вычисляет небольшой хеш фиксированной длины по статистикам MFCC и использует
его для классификации звуковых событий. Такой подход обменивает умеренное
снижение точности на представление примерно в 22 000 раз меньшего размера, что
подходит для IoT-узлов с ограничениями по пропускной способности, памяти и
энергопотреблению.

В экспериментах используется датасет звуков окружающей среды
[ESC-50](https://github.com/karolpiczak/ESC-50) (2000 клипов, 50 классов,
5 фолдов).

## Метод

Пайплайн, который воспроизводит все численные результаты в работе:

1. **Загрузка** каждого клипа в моно с частотой 22 050 Гц и пиковая
   нормализация волновой формы.
2. **Признаки** — 40 MFCC, агрегированные по времени как **среднее + std** для
   каждого коэффициента → **80-мерный** вектор.
3. **Нормализация** — z-нормализация для каждого файла отдельно (нулевое
   среднее и единичное std по 80 измерениям).
4. **Классификация**, два варианта:
   - **float** — 1-NN с L2-расстоянием по всем обучающим векторам
     (80 × `float64` = 640 байт на эталон).
   - **binary** — **80-битный хеш** = `sign` от среднего прототипа класса;
     классификация по **расстоянию Хэмминга** до ближайшего прототипа
     (10 байт).

Обучение выполняется на фолдах 1-3, тестирование — на фолдах 4-5 (стандартное
разбиение ESC-50).

| Константа | Значение |
|---|---|
| Частота дискретизации | 22 050 Гц |
| Окно FFT / шаг | 2048 / 512 |
| MFCC | 40 |
| Размерность признаков | 80 (среднее + std) |
| Длина хеша | 80 бит = 10 байт |

## Результаты

Точность на тестовой выборке (фолды 4-5):

| Конфигурация | Метод | Точность | k / n | Случайный базовый уровень |
|---|---|---:|---:|---:|
| ESC-10 | float (1-NN, L2) | 56.2% | 90/160 | 10.0% |
| ESC-10 | binary (80-bit) | 43.8% | 70/160 | 10.0% |
| ESC-50 | float (1-NN, L2) | 29.1% | 233/800 | 2.0% |
| ESC-50 | binary (80-bit) | **10.4%** | 83/800 | 2.0% |

Бинаризация стоит примерно 12 процентных пунктов на ESC-10 и примерно
19 пунктов на ESC-50: один 80-битный прототип на класс перестает разделять
50 спектрально похожих классов, но бинарный хеш все равно превосходит случайное
угадывание примерно в 5 раз на полном наборе.

Разбивки по классам для каждого запуска записываются в `results/`.

### Точность на подмножествах

Ожидаемая точность float (1-NN, L2) на произвольном небольшом подмножестве
классов, усредненная по **всем** подмножествам заданного размера (то же
разбиение train/test). Запуск:
`python3 experiment.py --subsets`.

| Размер подмножества | Комбинации | Средняя точность | Случайный базовый уровень | × базового уровня |
|---|---:|---:|---:|---:|
| 2 класса | 1225 | 88.2% | 50.0% | 1.76× |
| 3 класса | 19 600 | 80.4% | 33.3% | 2.41× |

Разброс по парам: минимум 50.0% (наименее разделимые, например `clock_tick`
против `cat`), медиана 90.6%, а 176 из 1225 пар достигают 100%. Точности по
подмножествам записываются в `results/subsets_pairs.csv` и
`results/subsets_triples.csv`.

## Быстрый старт

В репозиторий включены предварительно рассчитанный кеш признаков
(`features_cache.npz`) и файл с метками, поэтому эксперимент запускается
**без скачивания 1.7 ГБ аудио**:

```bash
pip install -r requirements.txt
python3 experiment.py                 # ESC-10 и ESC-50, float и binary
```

Другие параметры:

```bash
python3 experiment.py --config esc50  # только полный набор из 50 классов
python3 experiment.py --method binary # только бинарный хеш
python3 experiment.py --subsets       # + усредненная точность для 2 и 3 классов
python3 experiment.py --no-cache      # повторно извлечь признаки (нужно аудио)
```

Чтобы повторно извлечь признаки из исходного аудио, сначала скачайте датасет:

```bash
bash scripts/download_esc50.sh        # скачивает ESC-50/audio (~600 МБ zip)
python3 experiment.py --no-cache
```

## Структура репозитория

```
experiment.py              Полный пайплайн + оценка (единая точка входа)
features_cache.npz         Предварительно рассчитанные 80-мерные признаки для всех 2000 клипов
ESC-50/meta/esc50.csv      Метки и назначения фолдов (аудио не хранится в git)
scripts/download_esc50.sh  Скачивает исходное аудио (без git-сабмодуля)
results/                   CSV с точностью по классам и подмножествам, пересоздаются при каждом запуске
requirements.txt
LICENSE                    MIT (код); ESC-50 — CC BY-NC 3.0, см. LICENSE
```
